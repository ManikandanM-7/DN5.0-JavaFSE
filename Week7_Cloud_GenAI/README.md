## key things i learned this week

1. cloud is just someone else's computer - but with auto scaling, managed services, pay per use
2. EC2 = virtual machine, S3 = file storage, RDS = managed database, Lambda = serverless functions
3. prompt engineering matters a lot - same question written differently gives very different output
4. copilot is useful for boilerplate but you still need to understand what it generates
5. never put API keys or passwords in prompts or comments that copilot can read
